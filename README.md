# CP1 Biochemistry: the 150 key questions

150 multiple-choice questions, one per key fact, chosen by working through every lecture practice question on the CP1
biochemistry question page (learning questions and the untested primers excluded) and the biochem TAs' Fall 2026 CP1
mock exam, keeping the facts that answer the most of them, directly or by elimination. Each question has a Key fact box,
a "What it unlocks" dropdown (how the fact is tested, what it eliminates, links to the straight-recall questions), a
Slides dropdown, and a "Questions it helps you answer" dropdown with the non-obvious practice and TA questions,
answerable in place.

Live page: https://yoelplutchok.github.io/cp1-biochem-150-keys/
Built by `Fall Courses/_cp1keys/` (extract.py → make_jobs.py → jobs/*_out.json, *_hidden.json, *_add.json → patch.py → patch2.py → build.py).
